## 策略学院首页重构（Academy Home Redesign）
触发：用户请求 @frontend-design 优化策略学院首页。目标：提升视觉层次、信息架构清晰、加载快、适配移动/桌面。

### 问题诊断
旧版 6 个视觉同权重的「卡片块」堆叠在课程内容之前：brass 横幅（静态营销文案）+ header panel + 每日计划 + 2 个快捷操作 pill + 基础入门卡 + 概念图卡。1400px 桌面仍单列窄排。8 张雷同 LevelCard，看不出「我在哪、下一步是什么」。AcademyHome / LevelCard / DailyPlanCard 多处硬编码中文。

### 设计方向（签名元素「牌桌阶梯」）
- **Hero 继续学习**：唯一主 CTA（fresh / continue / allDone 三态）+ 进度环 + 3 项统计。
- **课程阶梯**：8 级课程以黄铜铆钉节点 + 发线脊柱纵向排列，活跃等级自动展开课程 chips（✓/▶/锁）。每个 chip 含状态图标 + 标题 + 时长；全完成等级显示「参加认证测验」。

- 色彩字体走既有 token（felt/walnut/ivory/brass + 语义色），display 标题 + numeric 数据，无新增依赖。

### 代码变更

## 变体切换器修复（VariantToggle Redesign）
触发：用户反馈「选择游戏变体」设计不美观、中文界面仍显示英文。

### 问题诊断
`src/shared/components/VariantToggle.tsx` 直接渲染 `VARIANT_CONFIG[variant].shortName`（硬编码英文 `Hold'em` / `Short Deck` / `Heads-Up`），完全不走 i18n——而 i18n 早已定义 `variant.name.standard` 等中文 key（标准德州/短牌德州/单挑）。样式用 `border-2` + Tailwind 颜色类 `border-brass-700 bg-brass-800`（非项目 token），视觉生硬。AcademyHome 的变体区块另散落为「设置条 + 独立骨架提示」两个 div，组合松散。

### 设计方向
- **分段控件（segmented control）**：单个圆角容器内嵌三个分段按钮；选中项黄铜渐变 + 阴影 + `border-brass-dark`；未选中项 `--ivory-muted` + 鼠标 hover 微亮 `--ivory` + 4% 白底；所有 token 走 `var(--walnut-*)` / `var(--brass-*)` / `var(--ivory-*)` / `var(--felt-deep)`。
- **i18n 化**：变体 label 用 `t('variant.name.' + variant)`，group aria-label 用 `t('variant.select_variant')`。
- **面板整合**：AcademyHome 的变体区块由「设置条 + 独立骨架提示」两段，整合为单个 `.panel.variant-panel`：左标题 + 联动副标题（实时显示当前变体名 + 课时数 + 骨架提示），右分段控件。
- **响应式**：移动端 <480px 分段按钮 `flex: 1 1 0` 等宽分布，避免小屏换行。

### 代码变更
- 重写 `src/shared/components/VariantToggle.tsx`：移除 cva 依赖，`useTranslation` 包裹，新增样式类全部走项目 token，接口（variants/onSelect/active/className）保持完全兼容；`VariantToggleComponent` type 保留导出。
- `src/features/strategy-academy/components/AcademyHome.tsx`：将原两段「eyebrow 设置条 + 条件骨架提示」替换为单个 `panel variant-panel`，副标题随 activeVariant 实时联动。

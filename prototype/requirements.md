# PokerLab · 牌室学院 — 初学者学习路径原型 · 需求记录

> 状态：本轮交付待整组确认 · 记录日期：2026-11-20
> 交付形态：PC 网站优先 + 移动响应式的可点击 HTML 交互原型（真实 DOM + 模拟数据，无后端）

## 1. 原始需求（用户原话）

> 我这个产品是希望打造一个初学者德州学习从入门到进阶的网站。希望结合现有功能设想，并可以适当提出教育学上的建议，打造一个具有设计感的 ui 界面。

## 2. 目标与用户

- **主用户**：零基础新手（PRD Persona A）——不知道先学什么、术语陌生、怕挫败；手机碎片时间 + 桌面系统学习。
- **次用户**：休闲进阶玩家（Persona B）——修补漏洞、要量化进步。
- **核心任务**：第一次打开 → 落座引导 → 看清「我在哪、下一步学什么」→ 学一课 → 课后检验 → 练一组 → 看到反馈与成长 → 明天还想来。
- **成功标准（原型可演示）**：上述闭环每一步可点击走通；进度/连击/ELO/复习队列随行为真实变化并持久化。

## 6. 教育学建议（本轮核心增量）

| # | 原理 | 原型落地 | 现有功能锚点 |
|---|---|---|---|
| 1 | **脚手架路径 / 最近发展区**（Vygotsky）：把「入门→精通」切成 4 阶段 8 课，每阶段只比当前能力高一步 | 首页旅程图：阶段节点 + 课程芯片 + 当前位置 lamp glow，永远只有一个「下一步」 | 理论 T1-T8 / 策略 L1-L8 分级 |
| 2 | **掌握学习**（Bloom）：达标才前进，避免「夹生饭」累积 | 课后检验 2/3 掌握门槛；阶段认证门禁；未过给「再读一遍」而非惩罚 | lessonAttempts / submitCertificationAttempt |
| 3 | **间隔重复**（Ebbinghaus）：在遗忘临界点复习 | SRS 到期队列置顶首页 + 进度中心；答错题自动入队 | progress SRS 系统 |
| 4 | **形成性反馈 / 反馈即教学**：错误要解释「为什么」并给补救路径 | 五级反馈 + EV 损失 + 你的决策 vs GTO 对比 + 相关课程芯片 | calculateGrade / relatedLessonId 闭环 |
| 5 | **认知负荷理论**（Sweller）：一次一个概念，新手收敛信息 | 课程 3 要点块 + 要点总结卡；新手首页渐进披露（训练场按训练次数解锁） | DESIGN.md §13.6 渐进式披露 |
| 6 | **刻意练习**（Ericsson）：针对弱项、难度自适应 | 今日计划按弱项优先（五维最低项置顶）；连错自动降档提示 | shouldDownshiftDifficulty |
| 7 | **双重编码**（Paivio）：视觉 + 语言双通道 | 13×13 范围网格直觉 + 文字解释；手牌示例用真实 CSS 扑克牌 | RangeGrid / hand-example 内容块 |
| 8 | **情境学习**：在真实牌局情境中练决策 | 场景卡（位置/底池/对手）先于问题呈现；复盘入口 | scenario-card / hand-history |
| 9 | **自我调节学习 / 元认知**：情绪与计划影响决策质量 | 情绪签到三态 + 导师人格化寄语 + 每日目标自选 | Emotion / Mentor 系统 |
| 10 | **动机保护**（自我决定理论）：奖励自主与胜任，不惩罚中断 | 冻结卡保护连击；完成用黄铜钢印而非红叉；连击断档温和提示 | awardStreakFreeze / stamp |

## 7. 视觉与文案基准

- 视觉唯一参考：仓库根 `DESIGN.md`（felt 绿呢 / walnut 胡桃 / ivory 象牙 / brass 黄铜四家族；低饱和语义色；纸张浮层；桌沿铜钉签名；反霓虹）。

- 字体：Fraunces（标题/数字铭牌）+ Inter Tight（正文）+ JetBrains Mono（数值），中文回退系统宋/黑。

## 8. 模拟范围与边界

- 模拟：路由跳转、课程完成与解锁、答题反馈、ELO/连击/SRS 变化、主题/导师/动效切换、localStorage 持久化。

- 进阶/精通阶段课程在原型中提供精简完整课节；正式产品以两院现有课程内容为准。

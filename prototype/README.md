# PokerLab · 牌室学院 — 初学者学习路径交互原型

> 从入门到精通的德州扑克学习网站原型 · 真实 DOM + 模拟数据 · 无后端
> 设计契约：仓库根 `DESIGN.md`「Private Card Room 私人牌室」v1.10 · 教育学建议见 `requirements.md` §6
> 视觉基线：神火双端基准图 r01 已整组确认（2026-11-21「认可，生成HTML 交互原型」），采用图见 `reference/`，出处与不采纳偏差见 `DESIGN.md` §0

## 启动

无需构建、无需依赖，任选其一：

1. **直接双击** `index.html`（file:// 协议即可运行，localStorage 持久化正常）
2. 本地服务（推荐，字体外链加载更稳）：
   ```bash
   cd prototype
   python -m http.server 8080
   # 浏览器打开 http://localhost:8080
   ```

字体走 Google Fonts（Fraunces / Inter Tight / JetBrains Mono）；离线时自动回退系统宋体/黑体/等宽，功能不受影响。

## 页面与跳转

| 视图 | 路由 | 入口 |
|---|---|---|
| 学习路径首页 | `#/home` | 侧栏「学习路径」/ 移动底栏「路径」 |
| 课程学习 | `#/lesson/:id` | 旅程图课程芯片 / 「继续学习」/ 侧栏「课程学习」 |
| 范围训练 | `#/drill` | 黄铜横幅旁训练场 / SRS「开始复习」/ 侧栏 |
| 每日速训 | `#/quick` | 黄铜横幅「开始速训」（3 题 · 每题 20s） |
| 进度中心 | `#/progress` | 侧栏「进度中心」/ 结算「查看成长」 |
| 浮层纸条 | — | 欢迎引导 / 牌室设置 / 课程完成 / 训练结算 / 锁定说明 |

核心闭环（已浏览器实测）：欢迎落座 → 首页看清当前位置 → 课程阅读 → 课后检验 ≥2/3 → 钢印完成 + 下一课解锁 → 训练作答 → 五级反馈 + GTO 对比 + 相关课程 → 结算（ELO / 连击 / SRS 真实变化）→ 进度中心复盘 → 明天继续。

## 可操作控件

- 答题：课程三选一（即时判定 + 解释）、训练平权三选项（fold/call/raise）、速训倒计时（超时按最劣动作计）
- 旅程：课程芯片点击（锁定课弹出掌握门禁说明）、阶段进度环
- 进度：情绪签到三态、SRS 开始复习、弱项训练入口
- 设置纸条：暗/亮主题、三导师人格、动效开关、演示解锁（跳过门禁预览全阶段）、重置演示数据
- 顶栏：主题快切、连击徽章、设置；移动端底栏五入口
- 持久化：全部状态存 localStorage（键 `pokerlab-prototype-v1`），刷新不丢

## 模拟边界

模拟：路由、解锁门禁、答题反馈、ELO/连击/SRS/成就变化、主题/导师/动效。
不模拟：账号、后端、真实 GTO 求解、手牌导入、i18n（原型中文单轨）。
进阶/精通段为精简完整课节；正式产品以两院现有课程内容为准。

## 验证

`tools/verify.mjs` 用 Playwright（chromium 无头）跑 20 步全链路 + 双视口（1440×900 / 390×844）：
欢迎→课程→测验→解锁→训练→反馈→结算→进度→主题→重置→移动溢出/触摸目标/倒计时/重复交互稳定性。
最近一次：**20/20 通过，0 JS 异常**；证据见 `verification/`（截图 + report.json）与 `verification.json`。
脚本借用主仓 `node_modules` 的 playwright-core（路径见脚本头部），本原型自身零依赖。
验证时阻断 Google Fonts 外链以保证无头环境确定性（2 条 console 资源错误即来源于此，非应用缺陷）。

# docs/agents — 文件所有权指南

> 状态：Current · 最后复核：2026-11-23
> 根 [AGENTS.md](../../AGENTS.md) 是全局约束、任务路由与跨模块能力归属的单一事实源；本页说明「文件归谁所有」与交付方式。

## 文件与维护

- [MODULE_MAP.md](./MODULE_MAP.md)：从代码生成的模块、路由、i18n 与依赖地图，不手改；改动路由 / 模块 / i18n 注册表后运行 `pnpm agents:map`。
- 项目不再维护自带子代理文件；执行层由全栈开发组插件代理按技能派单（详见根 AGENTS.md §Agent 协作）。

## 所有权规则

- **模块树即所有权**：`src/features/<module>/**` 归该模块；`src/shared/**` 为跨模块层；`src/app/`、`src/layouts/`、`src/i18n/`、`src/guards/`、`src/styles/`、`scripts/` 为平台层；`docs/**` 与 `README.md` 为文档层。
- **机器事实**：模块的入口组件、store / persist 版本、i18n 模块、允许跨模块引用与组件 / 测试数量以 `MODULE_MAP.md` 为准。
- **就近约束**：模块级红线写在 `src/features/<module>/AGENTS.md` 或 `src/shared/AGENTS.md`，不得与根 AGENTS.md 冲突。
- **跨模块能力**：非模块独属的能力登记在根 AGENTS.md §跨模块能力归属登记表（以持有文件表达归属）。

## 派单与交付

1. **先读再改**：检查工作区已有改动，读根约束、模块就近 AGENTS（如有）与任务相关入口；知识卡只作导航，冲突时以代码和 Current 文档为准。
2. **明确写域**：派单给出目标、独占文件、禁止改动区、依赖与验收命令，并说明是只读审查还是实施；执行方可凭证据驳回错误前提。
3. **单一写者**：模块源码与该模块双语文案由该模块所有者修改；共享组件、共同 locale、registry、配置与生成物须先指定唯一写者，同文件不并行编辑。
4. **先契约后并行**：跨模块变更先确定接口契约与唯一写者，各方按互斥文件执行；需要越界时报告目标文件、原因与影响面，等待协调，不自行扩大权限。
5. **分层验证**：执行方跑本批次定向检查；全部写者结束后统一复核实际 diff、同步文档 / 生成物并跑 `pnpm verify`。UI 与浏览器发布门禁按根 AGENTS.md 执行，不能用单测代替。
6. **如实交付**：返回「改动文件与结果 / 验证命令及退出码 / 未测与阻塞」三段简报，不粘全文。超时不等于通过；中断先核对已落盘修改，不盲目重跑、覆盖或回退。
7. **保留用户控制**：默认不 commit / push，不改变模型、工具、权限或用户已有工作；删除等破坏性动作按授权要求处理。

批量补测按模块拆分、只跑定向测试，主线统一覆盖率、全量验证与地图同步，详见 [测试规范](../testing/README.md) §13。

## 校验

```powershell
pnpm docs:check
pnpm agents:map:check
```

`docs:check` 校验文档链接、索引覆盖与状态声明；`agents:map:check` 校验 `MODULE_MAP.md` 与代码事实一致。两者已接入 `pnpm verify`，定向检查不能替代项目完整门禁。

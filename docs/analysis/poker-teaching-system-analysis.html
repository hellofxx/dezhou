<li><strong>动态难度适配</strong>：训练题难度与用户当前评分绑定，保持"i+1"最佳挑战区</li> <li><strong>评分变化可视化</strong>：每次训练后显示评分变化（+12/-5），段位提升有庆祝动画</li> <li><strong>综合段位</strong>：5维加权综合分，对应新手→入门→进阶→中级→高级→专家6个段位</li> </ul> <h3>5.5 P1：间隔重复（SRS）系统落地</h3> <p>将Chessable验证过的间隔重复技术应用于扑克知识记忆：</p> <ul> <li><strong>适用内容</strong>：翻前范围表、常见牌面策略点、牌力排名、下注尺度规则、对手类型识别特征</li> <li><strong>算法逻辑</strong>：答对→间隔延长（1天→3天→7天→14天→30天）；答错→重置间隔到1天</li> <li><strong>每日复习队列</strong>：打开App首先展示"今日待复习N张卡片"，类似Anki的Due卡片</li> <li><strong>新学+复习混合</strong>：每日训练=70%新内容+30%复习（根据熟练度动态调整比例）</li> <li><strong>与训练题整合</strong>：SRS调度的不是"闪卡"而是实际的训练题——复习就是做对应的Drill</li> </ul> <h3>5.6 P2：本土化内容线规划</h3> <p>针对中文用户最常遇到的本土牌局环境，新增第6条学习路径——<strong>"本土低级别盈利路径"</strong>：</p> <div class="callout"> <div class="callout-title">🇨🇳 本土化学习路径核心内容</div> <p> <strong>模块1：Limp局应对策略</strong>——多人平跟底池的范围调整、隔离加注尺度、翻后多人底池打法<br> <strong>模块2：Ante/Straddle策略</strong>——强制Straddle改变底池赔率后的翻前调整、Ante对开池范围的影响<br> <strong>模块3：深筹码调整</strong>——200bb+深筹的隐含赔率计算、小对子/同花连张的价值变化<br> <strong>模块4：玩家类型剥削</strong>——如何打跟注站(Calling Station)、如何打疯鱼(Maniac)、识别并 exploitation 常见漏洞<br> <strong>模块5：GTO与剥削平衡</strong>——什么时候用GTO、什么时候偏离GTO最大化EV、低级别GTO的误区<br> <strong>模块6：情绪管理基础</strong>——识别Tilt前兆、止损策略、session时间管理、下风期心理建设 </p> </div> <h3>5.7 反馈机制升级建议</h3> <p>参考GTO Wizard的五级评分和PokerSnowie的错误分级，将现有二元反馈（对/错）升级为更细粒度的五级反馈：</p> <div class="table-wrap"> <table> <thead> <tr> <th>等级</th> <th>名称</th> <th>评判标准</th> <th>反馈颜色</th> <th>EV损失阈值</th> </tr> </thead> <tbody> <tr>
